# Named checks tests/ui/keys.mjs must print as passing: <phase>|<label prefix>|<predicate>.
# gate.sh step 3 requires a line opening with "ok   <label prefix>" for every row up to the phase
# (cumulative) or at it (--phase-only). The predicate is the contract the check implements; the
# gate cannot read it, so code-review grades each check's code against it. Shared rules:
# - "waits" means: wait for #graph[data-move] to change from its value before the action, then for
#   data-anim="0". Never wait on data-anim alone (it is still "0" before the first frame).
# - "timeline" means: an addInitScript MutationObserver records every write of data-theta, data-psi,
#   data-dist, data-anim and data-labels with performance.now().
# - "positions" means window.__oktPos (installed empty by addInitScript; the client fills it from the
#   uploaded position buffer on every upload) and "projects" means applying data-view (the 16-float
#   view-projection the GL drew the last frame with) to those positions, in the test.
# - "idx" means /api/index fetched by the test; counts computed from it never come from the client.
# Existing checks (FILES, GRAPH walk, reading, ANY) keep passing; keys.mjs's exit status covers them.
